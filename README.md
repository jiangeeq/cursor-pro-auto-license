一个强大的 Cursor Pro 授权管理工具，提供自动化账号注册、设备管理、授权生命周期管理等功能，帮助您高效管理 Cursor Pro 的使用。



## 功能特性

### 🚀 核心功能

- **自动化账号注册**：一键注册 Cursor Pro 账号
- **设备 ID 重置**：延长试用期，突破使用限制
- **授权管理**：创建、查看和管理授权码
- **设备管理**：监控已绑定设备状态
- **账号池**：集中管理所有账号使用情况

### 📊 数据统计

- 实时查看有效授权数量
- 监控已绑定设备状态
- 统计账号使用情况
- 查看最近活动日志

## 系统概览

## 快速开始

### 安装方法

```
git clone https://github.com/jiangeeq/cursor-pro-auto-license.git
cd cursor-pro-auto-license
python run.py
```

### 使用步骤

1. 激活授权：

   ```
   授权码: b9f8-20250705-6be4-3467
   ```

2. 点击"独享注册"按钮自动注册账号

3. 如需重置机器ID，点击"重置机器ID"按钮

4. 或直接点击"一键畅享"完成全部操作
